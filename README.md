
# Azurion Hub

Azurion Hub is a premium, lightweight Roblox script hub designed for high-performance automation and game-specific enhancements.  
It uses a modular architecture to deliver real-time updates and seamless multi-game support.

## 🚀 Loader

Execute the official loader below in your executor:

```lua
getgenv().language = "en" -- pt
loadstring(game:HttpGet("https://raw.githubusercontent.com/azuriondeve/azurionhub/refs/heads/main/loader.lua"))()
```

## 🎮 Supported Games

Currently supported games:

* ✅ **Escape the Tsunami for Brainrots** (Active)
* ✅ **99 Nights** (Active)

## ✨ Hub Features

* **Keyless**
  It doesn't have a key system, so that's a good advantage.

* **Dynamic Loading**
  Loads only the required modules for the current game, reducing memory usage.

* **Obfuscation Friendly**
  Compatible with high-tier executors without false-positive crashes.

* **Auto-Update Engine**
  Always fetches the latest version of all modules. No need to re-copy scripts.

* **Clean UI**
  Simple and efficient interface focused on usability.

## 🛠 Requirements

To run Azurion Hub, you need:

* **Environment:** Roblox (latest version)
* **Functions:** `loadstring`, `HttpGet`, `getgenv` (recommended for saving settings)
* **Executor:** Level 7+ or compatible internal executor
